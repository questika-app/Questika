Дизайн-система главного экрана

Единый источник правды для дизайнеров, которые делают остальные экраны. Здесь токены, компоненты с состояниями, правила поведения и чек-лист. Работает в любом инструменте: Penpot, Figma Free, Sketch, Affinity или сразу в коде.

Как пользоваться

  • Берите цвета, размеры и радиусы только из этой страницы. Новые значения не вводим без согласования.
  • Токены в конце страницы скопируйте как CSS или как JSON (формат W3C Design Tokens, подходит для импорта в Penpot и Tokens Studio).
  • Базовый размер макета 430 × 932. Сетка 4/8, боковые поля 16.
  • Поведение (шторка, лента, выполнение задач) смотрите в живом прототипе, а здесь только правила.

Принципы

  • Сверху мир, снизу дела. Фото героя занимает верх экрана, задачи живут в белой нижней шторке.
  • Фиолетовый — действие, оранжевый — награда. Оранжевый только для прогресса, колец и галочек выполнения.
  • Один акцент на блок. Нейтральные теги и серые подсказки, цветное только главное.
  • Подсказки вместо текста. Подзадачи, теги и время выводим мелкими метками, а не абзацами.

Поведение

Нижняя шторкасвёрнута (верх на 620) и полный экран (верх 0). Тянется за ручку и заголовок. Сдвиг больше 50px переключает состояние, меньше возвращает назад. Тап по ручке переключает.
Полный экраншапка скрыта, сверху отступ 46 под статус-бар, справа появляется крестик.
Выполнение задачистрока исчезает из списка, карточка в ленте заменяется следующей, обновляются счётчик, сегменты прогресса и сундук.
Заголовок шторкижирная дата «Чт, 12 ноября», справа нейтральная кнопка со стрелкой.
Пустые состояниявсе задачи закрыты: «Всё сделано ✨», сундук светится.

Чек-лист нового экрана

  • Цвета, шрифт, радиусы и тени только из токенов.
  • Есть фото или иллюстрация сверху, либо сознательно нет, но тогда фон экрана из градиента.
  • Один основной фиолетовый акцент, оранжевый только для награды.
  • Все состояния компонентов нарисованы: обычное, текущее, выполненное, пустое, загрузка, ошибка.
  • Нижняя панель и аватар с кольцом на месте и не перекрывают контент (отступ 150 снизу у списков).
  • Тексты на русском, без длинных абзацев, метки короткие.
